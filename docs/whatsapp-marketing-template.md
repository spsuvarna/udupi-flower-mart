## Consent rule

The website's **Get WhatsApp offers** button opens a customer-initiated message containing explicit consent. Retain that incoming message as the opt-in record. Honor `STOP` immediately and keep unsubscribed numbers on a suppression list. Never commit contact lists, access tokens, phone-number IDs or other customer data to this repository.
